# State-level annual mortality rates by cause among 18-20 year-olds

A dataset containing state-level annual mortality rates for select
causes of death, as well as data related to the minimum legal drinking
age and alcohol consumption.

## Usage

``` r
MortalityRates
```

## Format

A data frame with 5508 rows and 12 variables:

- year:

  Year of observation

- state:

  identifier for state

- count:

  Number of deaths

- pop:

  Population size

- legal:

  Proportion of 18-20 year-old population that is legally allowed to
  drink

- beertaxa:

  Beer taxation rate

- beerpercap:

  Beer consumption per capita

- winepercap:

  Wine consumption per capita

- spiritpercap:

  Spirits consumption per capita

- totpercap:

  Total alcohol consumption per capita

- mrate:

  Mortality rate per 10,000

- cause:

  Cause of death
